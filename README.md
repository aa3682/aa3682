# Alex Alonso

15+ years in wealth management and investment advisory, including The Vanguard Group and TIAA.

I build open, plain-English guides for solo and small RIAs putting AI to work without creating a compliance problem.

## Guides

- **[AI for the Solo Advisor](https://advisor-ai-guide.vercel.app)**: using general-purpose AI tools inside a small advisory practice, fitted to an existing compliance program.
- **[The Independent Path](https://solo-ria-guide.vercel.app)**: a 12-step path to establishing an independent RIA, from deciding to go independent through staying registered.
- **[Financial Planning Guide](https://financial-planning-guide.vercel.app)**: personal financial planning organized around the planning process, with reference material for practitioners.

## How they're built

Every guide starts from [guide-template](https://github.com/aa3682/guide-template): Nextra 4, a process-first structure, and a CLAUDE.md that drives drafting through Claude Code. Use it to start your own.

## Note

Everything here is educational. Nothing is investment, legal, or compliance advice, and I'm not offering advisory services.
